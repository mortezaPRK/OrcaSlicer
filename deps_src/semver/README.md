# semver.c

Based on [upstream v1.0.0](https://github.com/h2non/semver.c/tree/v1.0.0).
The upstream tag still labels its header as 0.2.0; the vendored version macro
reflects the release tag.

OrcaSlicer retains two-component versions, four-component Bambu versions,
`dev` prerelease ordering, copy helpers, and integer-width portability fixes.
